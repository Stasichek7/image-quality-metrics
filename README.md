# Image Quality Assessment Using MSE and PSNR

This Python program generates a grayscale image, adds Gaussian noise, and evaluates image quality using Mean Squared Error (MSE) and Peak Signal-to-Noise Ratio (PSNR).

## Features
- Generates a synthetic grayscale image using NumPy.
- Adds Gaussian noise to simulate image degradation.
- Calculates MSE and PSNR.
- Visualizes the original and noisy images using Matplotlib.

## Requirements

```text
numpy
matplotlib
```

## Run the program

```bash
pip install numpy matplotlib
python psnr_image_quality.py
```

## Purpose

The project demonstrates basic image quality assessment techniques used in image processing and multimedia systems.
